# 先把工具准备好

本章按下面顺序做完，就可以发出第一条指令：

1. 安装 Workbuddy 并完成登录
2. 按用途选择当前使用的模型
3. 将本地文件拖入对话框

本书默认使用 Workbuddy 作为工作环境。Workbuddy 是一款可在计算机上安装的人工智能办公助手，支持把本地文件拖入对话框，读者也可按用途切换模型。字号、项目、文件路径、语音输入、录音转写等用法，随后各章按需要再讲。需要把整理好的大纲做成演示文稿时，到「你做做」。需要查阅境外模型、计算机操作、邮件收发或自动填表时，到附录。

## 安装与登录

提前准备 Windows 与 macOS 的安装程序。按本单位规定的方式登录，包括账号登录，或连接本单位指定的内部网络地址。单位对办公软件有统一部署要求的，从其规定，不得自行改用未经批准的渠道。

【截图：Workbuddy 安装完成后的主界面】

登录后打开对话框，再进入下一步。

## 按用途选择模型

打开模型选择入口后，按费用和能力分成下面三档来选用。下列名称以常见写法为例，本机界面上的显示可能略有不同，按用途对号入座即可。日常使用可先把免费模型设为默认，遇到下面几类工作，再换成 Flash 模型或高级模型。

### 免费模型

日常对话和简单修改，使用免费模型即可，例如腾讯混元 Hy3、腾讯混元 Hy4（界面中有时写为 hy3、hy4）。下列工作可以使用这一档：

- 拿一份现成材料，向它问几个问题
- 把口头交代写成几条
- 改一改语气和篇幅
- 把口语改成书面语

这类工作改完还可以再改一版，先用免费模型完成即可。

### 费用较低的 Flash 模型

材料较多、需要较快给出一版可用结果时，可选用费用较低的 Flash 模型，例如 DeepSeek-V4.1-Flash、智谱 GLM-5.3-Flash。下列工作可以使用这一档：

- 看完一个文件夹，列出该办的事
- 整理会议纪要初稿
- 按现成格式改一改说明
- 把长稿压成简短汇报
- 从来文里摘出时间、地点、人员

Flash 模型速度较快、费用较低，适合处理量大、结构比较清楚的工作。

### 高级模型

需要查找核对依据、比较方案、核算数字，或起草较为正式的文稿时，可选用高级模型，例如 DeepSeek-V4-Pro、智谱 GLM-5.3、月之暗面 Kimi K3.1 Pro。下列工作可以使用这一档：

- 查找政策，并写明出处
- 比较几套方案或口径
- 核对数字和表格
- 想想汇报时可能被问什么
- 起草准备对外发出的文稿

事实、数字和出处仍须由人核对。拿不准时，可先用免费模型或 Flash 模型写出草稿，再换高级模型复核关键表述。

## 本地文件直接拖入

红头文件、Word、PDF、Excel 和照片，可以直接拖入对话框。拖入前先按「安全要求」一章做脱敏。

拖入之后，再用一句话说要它做什么。例如：「请阅读这份通知，列出本单位应办事项。」又如：「下面这段话请改成正式通知。」

## 发出第一条指令

做完上面几步，按下面顺序核对一遍：

1. 打开 Workbuddy 并完成登录
2. 按用途选好当前使用的模型
3. 拖入一份已脱敏的文件，或只写口头说明
4. 用键盘写出一句完整交代
5. 在对话框里阅读返回的文字

第一条指令不妨写得很短。例如请它用三句话概括刚提供的通知，或把一句口头催办改成短通知。对话框里出现返回的文字，这一章的准备就完成了。

遇到问题时，可按下面处理：

- 拖入后对话框里没有出现文件名，检查是否拖进了当前打开的对话框
- 返回文字不对题，把交代写具体一些，或换一档模型再试

然后进入下一章「你改改」。

## 当次练习

用约五分钟完成本练习，材料须已经脱敏。以下仅为示例，供对照练习。

1. 打开 Workbuddy，确认已登录。
2. 先用免费模型；若材料较长，再换成 Flash 模型。
3. 将一份本单位已脱敏的短通知、会议纪要或工作信息（Word 或 PDF）拖入对话框。
4. 写出一句交代，例如：「请阅读这份材料，用三句话概括它要求本单位做什么。」
5. 查看返回结果；结果仅作练习，不外发。

完成本练习后，即可进入第一部「开口即用」的第一章「你改改」。
