# 先把工具准备好

先完成下面几步，读者就能发出第一条指令：

1. 把 Workbuddy 装好
2. 把聊天字号调大
3. 确认文件拖得进对话框，或可以把本地路径发给助手
4. 确认话能对着麦克风说进去

本书默认使用 Workbuddy 作为工作环境。Workbuddy 是一款可在计算机上安装的人工智能办公助手，支持项目（Project）、本地文件拖放和按路径读取，并可以按用途切换模型。会议转写和拍摄纸质文件的基本用法写在本章后半部分。需要把整理好的大纲做成演示文稿时，到「你做做」。需要查阅境外模型、计算机操作、邮件收发或自动填表时，到附录。

## 安装与登录

提前准备 Windows 与 macOS 的安装程序。按本单位规定的方式登录，包括账号登录，或连接本单位指定的内部网络地址。单位对办公软件有统一部署要求的，从其规定，不要自行改用未经批准的渠道。

登录成功后，先做两件事：

1. 增大聊天区域的字号，使长时间阅读不费力
2. 记住呼出对话框的快捷键，便于在处理其他文稿时随时唤出

字号和快捷键的具体位置因版本略有不同，以本机界面为准。

## 用项目分开不同工作

项目（Project）用来把一项较完整的工作单独收在一处。建项目时，可按这句口诀办理：一件事，一个文件夹。在 Workbuddy 里，这个文件夹就是一个项目。下列工作宜各自建立项目，并把相关文件、既有规章和领导要求放入其中：

- 一次专题汇报
- 一轮监督检查
- 一份年度工作要点

互不相关的事项不要放在同一段连续对话里。上下文混在一起，容易互相干扰，也可能把甲事项的表述带到乙事项的草稿中。

建立项目后，日常交代都在该项目内进行。换一项工作时，切换到对应项目，或新建一个。不要图省事在旧对话末尾继续说新事。

## 本地文件直接拖入

红头文件、Word、PDF、Excel 和照片，可以直接拖入对话框，不必长篇复制粘贴。拖入前先按「安全要求」一章做脱敏，去掉：

- 密级标识
- 内部编号
- 可识别的个人信息
- 未公开数据

纸质材料可先用手机拍成照片，或保存为 PDF，再拖入。

拖入之后，用一句话说明要它做什么。例如：「请阅读这份通知，列出本单位应办事项。」又如：「下面这段话请改成正式通知。」把材料拖入对话框，再用口头说明要它做什么，二者合在一起，才构成完整的一次输入。

## 用文件路径代替上传文件

逐份上传文件比较费时：每增加一份，就要再上传一次。一个文件夹里可以存放许多文件，把这个文件夹的完整路径发给人工智能助手，它即可按路径直接读取其中的材料。单份文件也可以只发该文件的路径。这也与「一件事，一个文件夹」的口诀一致。发给助手之前，仍须按「安全要求」一章做脱敏。

把路径粘贴进对话框后，用一句话说明要它做什么。例如：「请阅读这个文件夹里的通知，列出本单位应办事项。」路径和口头说明合在一起，才构成完整的一次输入。

获取路径的方法如下。

### 在 Windows 中复制路径

1. 打开文件资源管理器，选中该文件夹；若只有单份文件，选中该文件
2. 右键单击；若菜单中没有「复制为路径」，按住 Shift 键再右键单击
3. 选择「复制为路径」
4. 回到 Workbuddy，把路径粘贴进对话框，并说明要它读取这个文件夹或这份材料

复制得到的路径一般形如 `D:\工作\某专项` 或 `D:\工作\某专项\通知稿.docx`。使用「复制为路径」时，两端可能带有英文引号，一并粘贴即可。

【截图：Windows 右键菜单中的「复制为路径」】

### 在 macOS 中复制路径

1. 打开访达，选中该文件夹；若只有单份文件，选中该文件
2. 按住 Option 键（键盘上标有 ⌥ 的键），再右键单击
3. 选择「将……拷贝为路径名称」；有的系统版本可在选中后按 Command + Option + C，效果相同
4. 回到 Workbuddy，把路径粘贴进对话框，并说明要它读取这个文件夹或这份材料

复制得到的路径一般形如 `/Users/某用户名/Documents/某专项` 或 `/Users/某用户名/Documents/某专项/通知稿.docx`。

## 按用途选择模型

Workbuddy 可以按用途切换模型。可按费用和能力，分成下面三档来选用。下列名称以常见写法为例，本机界面上的显示可能略有不同，按用途对号入座即可。日常使用可先把免费模型设为默认，遇到下面几类工作，再换成 Flash 模型或高级模型。

### 免费模型

日常对话和简单修改，使用免费模型即可，例如腾讯混元 Hy3、腾讯混元 Hy4（界面中有时写为 hy3、hy4）。下列工作可以使用这一档：

- 拿一份现成材料，向它问几个问题
- 把口头交代写成几条
- 改一改语气和篇幅
- 把口语改成书面语

这类工作改完还可以再改一版，先用免费模型完成即可。

### 费用较低的 Flash 模型

材料较多、需要较快给出一版可用结果时，可选用费用较低的 Flash 模型，例如 DeepSeek-V4.1-Flash、智谱 GLM-5.3-Flash。下列工作可以使用这一档：

- 看完一个文件夹，列出该办的事
- 整理会议纪要初稿
- 按现成格式改一改说明
- 把长稿压成简短汇报
- 从来文里摘出时间、地点、人员

Flash 模型速度较快、费用较低，适合处理量大、结构比较清楚的工作。

### 高级模型

需要查找核对依据、比较方案、核算数字，或起草较为正式的文稿时，可选用高级模型，例如 DeepSeek-V4-Pro、智谱 GLM-5.3、月之暗面 Kimi K3.1 Pro。下列工作可以使用这一档：

- 查找政策，并写明出处
- 比较几套方案或口径
- 核对数字和表格
- 想想汇报时可能被问什么
- 起草准备对外发出的文稿

事实、数字和出处仍须由人核对。拿不准时，可先用免费模型或 Flash 模型写出草稿，再换高级模型复核关键表述。

## 语音输入

建议在计算机和手机上安装并使用微信输入法，用它的语音功能向人工智能助手交代工作。安装完成后，在输入法设置中开启语音输入，即可在 Workbuddy 的对话框里对着麦克风说话。

日常向工作人员说明任务时使用的说法，可以直接对着麦克风说出。说错了，补一句「刚才那句不计算在内」，再把正确意思说一遍，由系统整理要点。语音用来降低打字负担。对象、时限、文体、语气，该说的仍要说清。

## 会议转写与纸质材料

会议时间较长，或手头只有纸质文本时，可配合使用下列方式：

- 手机录音并转为文字
- 讯飞录音笔或同类设备
- 飞书、钉钉等会议记录转写
- 用手机把纸质文件拍下来，保存为照片或 PDF，再拖入 Workbuddy

## 发出第一条指令

至此，读者应当能够完成下列动作：

1. 打开 Workbuddy
2. 进入或新建一个项目
3. 拖入一份已脱敏的文件，或把本地路径粘贴进对话框，或仅用口头说明
4. 用语音或键盘说出一句完整交代
5. 看到助手返回的第一段文字

第一条指令的内容可以很简单。例如请它用三句话概括刚提供的通知，或把一句口头催办改成短通知。这一步是为了确认四件事：

- 工具能用
- 话能进去
- 文件能进去
- 结果能看见

遇到问题时，可按下面处理：

- 返回结果读起来费力，先回到字号设置
- 文件未被读取，检查是否拖入当前项目的对话框，或检查粘贴的路径是否完整
- 语音识别有误，用「刚才那句不计算在内」纠正后再说一遍

做好这些准备后，进入下一章「你改改」。

## 当次练习

用约五分钟完成本练习，材料须已经脱敏。

1. 在 Workbuddy 中新建一个项目，名称可写「某局××专项练习」一类代称。
2. 将一份本单位已脱敏的短通知、会议纪要或工作信息（Word 或 PDF）拖入该项目，或把该文件所在文件夹的本地路径粘贴进对话框。
3. 用语音说一句交代，例如：「请阅读这份材料，用三句话概括它要求本单位做什么。」
4. 查看返回结果，确认字号清晰、文件已被读取；结果仅作练习，不外发。

完成本练习后，即可进入第一部「开口即用」的第一章「你改改」。
