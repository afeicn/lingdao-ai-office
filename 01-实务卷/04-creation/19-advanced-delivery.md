# 第十九章　阶段四进阶课｜跨工具制作与交付

**把 WorkBuddy 生成的文件转入办公软件复核，按要求保存和交付**

WorkBuddy 可以生成 Word、Excel、PPT、PDF 等产物，也可以在本地文件夹中打开文件，交由系统默认应用继续处理。

## 开始前确定交付要求

先明确使用哪份已核实材料作为数据来源、需要哪些文件、接收人员使用什么软件，以及最终文件保存到哪里。任务要求应写出文件类型，例如 `.xlsx`、`.pptx`、`.docx` 或 PDF；需要保留可编辑版本时，也要说明。

## 从 WorkBuddy 打开并保存产物

任务完成后，先在结果区查看「产物」「工作空间文件」和「变更」，确认文件已生成到预定位置。产物菜单可打开文件夹、使用系统默认应用打开，或另存到指定目录。

WorkBuddy 的独立文件浏览器支持查看 Word、Excel 和 PPT。Office 文件需要手动保存；关闭窗口时，界面会提示尚未保存的改动。若文件已在别处发生变化，WorkBuddy 会提示版本冲突。重要修改可以另存为新文件，再对照原件确认差异。

文件名可包含事项名称、日期和版本，例如「季度运行情况汇报_2026Q4_v2.pptx」。不同版本分别保存，避免把初稿、审定稿和对外版混在一起。

## 按文件类型逐项复核

| 文件类型 | 打开后重点检查 |
| --- | --- |
| Excel 工作簿 | 数据来源、公式、单位、汇总行、隐藏行列和筛选范围；重新计算一项关键结果。 |
| Word 文档 | 标题层级、日期、人名、数字、表格、分页和引用出处；确认修订内容已保存。 |
| PPT 演示文稿 | 每页标题、数据标签、单位、图表口径、字体、图片裁切和页间逻辑；重点核对结论是否超出来源材料。 |
| PDF 文件 | 页数、换页、字体、图表和表格边界；确认它与审定版本一致。 |

检查文件内容时，既要对照 WorkBuddy 结果区，也要在实际交付软件中打开文件。预览正常不代表其他电脑上的字体、分页和公式显示完全一致。

## 怎样把跨工具制作与交付用好

涉及尚未审定的数字、政策口径和工作安排时，先把待核内容标出。正式报送或对外发布前，按单位流程审定。尚未获得授权时，不要求 WorkBuddy 上传云端、生成分享链接或发送文件。

WorkBuddy 的产物菜单提供分享链接、微信或企业微信发送，以及上传到资料库、腾讯文档和知识库等功能。使用这些入口前，领导干部应确认接收对象、链接访问范围、云端位置和账号授权符合本单位要求。分享链接可供接收者查看产物，发布前要按规定限定范围；内部材料须使用获准的存储和传递方式。

文件需要修改时，先另存新版本并核对差异。结果需要对外报送时，按文件审批流程确认最终版、附件和接收渠道，再由有权人员发送。

## 当次练习

练习约需十分钟，使用上面的模拟数据和临时工作空间。

1. 让 WorkBuddy 生成包含40项总数、34项完成、4项进行中、2项延期和85%完成率的 `.xlsx` 工作簿。
2. 在 Excel 或 WPS 表格中打开工作簿，核对数量合计和完成率公式。
3. 让助手根据已核对的工作簿生成两页 `.pptx`，只使用表内信息。
4. 在 PowerPoint 或 WPS 演示中逐页检查数字、标题、单位、图表和字体，并保存为新版本。
5. 如果练习要求 PDF，再用单位认可的工具生成 PDF，并核对页数和内容；练习文件不上传、不分享。

## 记忆方法：定来源、核内容、开原件、存新稿、按权交付

先确认数据来自哪份材料，再核对生成内容；用实际办公软件打开原文件，修改时另存新稿，最后按单位授权的渠道交付。
